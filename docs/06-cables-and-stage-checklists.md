# Кабелі, обладнання та чеклісти для різних сцен

## Мета

Підготувати переносний комплект без припущення, що майданчик матиме потрібні кабелі, входи або спосіб моніторингу. Цей файл не замінює фактичний routing у MainStage чи мікшері; він допомагає зібрати правильні речі до виїзду.

## Офіційна основа

- [Allen & Heath CQ-12T Technical Datasheet](https://www.allen-heath.com/content/uploads/2023/10/CQ-12T-Tech-Datasheet.pdf), перевірено 2026-07-26 — CQ-12T має два `Main LR` XLR-виходи, шість TRS-виходів і USB-B для multichannel audio.
- [Zoom AMS-24 Operation Manual](https://zoomcorp.com/manuals/ams-24-en/), перевірено 2026-07-26 — `OUTPUT A` є парою impedance-balanced 6.3 mm TRS виходів; USB Type-C кабель має підтримувати передавання даних; перед підключенням колонок рівень AMS-24 треба встановити в `0`.
- [Bose S1 Pro+ Owner’s Guide](https://assets.bose.com/content/dam/Bose_DAM/Web/consumer_electronics/global/products/speakers/S1PROP-SPEAKERWIRELESS/pdf/872237_og_bose-s1-pro_plus_en.pdf), перевірено 2026-07-26 — Channel 3 6.35 mm TRS line input є mono; AUX 3.5 mm є stereo.
- [CQ-12T Getting Started Guide](https://support.allen-heath.com/hc/en-gb/articles/41142443246993-CQ-12T-Getting-Started-Guide), перевірено 2026-07-26 — `Main Outputs` є `Main L/R`; USB-B є audio/MIDI interface.

## Як читати цей чекліст

`Підтверджено` означає, що роз’єм або властивість пристрою підтверджено офіційною документацією. `Потребує звірки` означає, що тип кабелю залежить від остаточного routing, який поки навмисно не зафіксований. Не купуй кабель лише за цією таблицею: спершу зістав обидва кінці з фактичним роз’ємом на твоєму обладнанні та входом майданчика.

## Сценарій 1: сольний / малий виступ з однією Bose S1 Pro+

### Брати додатково

| Річ | Кількість | Навіщо |
| --- | ---: | --- |
| **Один** інтерфейс: CQ-12T **або** Zoom AMS-24 | 1 | Не підключати обидва як audio interface одночасно |
| USB data cable до обраного інтерфейсу | 1 | MacBook → інтерфейс; для AMS-24 кабель має підтримувати data transfer |
| Кабель від погодженого mono line output до Bose | 1 | Bose має mono 6.35 mm TRS line input; точний інший кінець залежить від обраного output і буде зафіксований після routing |
| Bose S1 Pro+ + її живлення | 1 + 1 | Відтворення для невеликої сцени |

### Перевірити до виходу

- [ ] Усі backing tracks мають схвалену mono-версію або документально підтверджене mono сумування. Не подавати один stereo-канал як «mono».
- [ ] Bose має достатній заряд або підключене живлення.
- [ ] Рівень output інтерфейсу та level Bose зменшені до підключення; див. [правила безпеки](05-audio-safety-and-power.md#cable-safety-rules).
- [ ] Не використовується `AUX` Bose як заміна line input без окремого рішення: це інший, 3.5 mm stereo-вхід.
- [ ] AIRSTEP Lite керує MainStage після Bluetooth reconnect.

## Сценарій 2: малий майданчик із Zoom AMS-24 і зовнішньою акустикою / мікшером

### Брати додатково

| Річ | Кількість | Навіщо |
| --- | ---: | --- |
| Zoom AMS-24 | 1 | Обраний audio interface |
| USB-C data cable | 1 | MacBook → AMS-24; не використовувати cable лише для charging |
| Пара 6.3 mm TRS line cables для `OUTPUT A L/R` | 2 | AMS-24 має пару balanced `OUTPUT A`; для stereo до двох входів майданчика |
| Адаптери / кабелі до входів майданчика | за потреби | Лише після того, як FOH назве свій тип приймального входу; не передбачати його заздалегідь |

### Перевірити на soundcheck

- [ ] `OUTPUT A L` і `OUTPUT A R` доходять до двох відповідних каналів майданчика, якщо працюємо в stereo.
- [ ] Якщо майданчик дає один mono-канал, застосований погоджений mono mix, а не тільки `L` чи `R`.
- [ ] Перед підключенням колонок `AMS-24 volume` = `0`; перед підключенням джерел `Gain 1/2` = `0`, `48V` = `OFF`.
- [ ] Індикатори входів AMS-24 не світяться червоним: Zoom визначає це як clipping.
- [ ] `LOOPBACK` не використовується без окремого призначення; офіційний посібник застерігає, що monitoring у програмі при ввімкненому LOOPBACK може створити feedback loop.

## Сценарій 3: велика сцена з CQ-12T і FOH

### Брати додатково

| Річ | Кількість | Навіщо |
| --- | ---: | --- |
| CQ-12T + штатний блок живлення | 1 + 1 | Обраний мікшер та USB interface |
| USB cable MacBook → CQ `USB-B` | 1 | Дані й audio interface; перевірити, що він підходить до портів конкретного MacBook і CQ |
| XLR-кабелі `FOH-L` і `FOH-R` | 2 | CQ-12T має balanced XLR `Main L/R`; ці два канали передають stereo mix у два канали FOH |
| Короткі запасні XLR-кабелі | 1–2 | Заміна у разі пошкодження; точну довжину обрати під звичну сцену |
| Телефон / планшет із CQ MixPad | 1 | Додаткове керування мікшером; спосіб мережевого з’єднання визначається на майданчику |

### Що сказати FOH до soundcheck

> Я віддаю готовий stereo mix зі свого Allen & Heath CQ-12T: два balanced XLR канали, `Left` і `Right`, із line-level виходу. Будь ласка, підкажіть рекомендований спосіб прийняти ці два канали на вашому FOH і чи потрібен pad або інша підготовка.

Це повідомлення описує зафіксований намір, але не змінює самостійно правила gain staging майданчика. FOH підтверджує, куди саме підключати `FOH-L` і `FOH-R`.

### Перевірити на soundcheck

- [ ] FOH чує обидва канали й називає їх `L` та `R` правильно.
- [ ] Подається готовий mix: backing track + гітара після TC-Helicon + вокал після TC-Helicon.
- [ ] На CQ-12T немає clipping, а FOH не просить небезпечного підвищення output level.
- [ ] MacBook бачить CQ-12T і MainStage відтворює тестовий звук **після** того, як тест сумісності Tahoe буде успішно записано в [реєстрі](04-compatibility-register.md).
- [ ] У разі одного доступного FOH-каналу перейти до попередньо перевіреного mono сценарію, а не імпровізувати з `Main L` або `Main R`.

## Мінімальна візуальна перевірка перед виходом

```text
MacBook + зарядка  □     AIRSTEP Lite  □     Гітара  □     SM58 + XLR  □
TC-Helicon + PSU  □     Обраний інтерфейс  □     USB data cable  □
Кабелі TC → interface  □     Вихідні кабелі до сцени  □     Живлення  □
```

## Очікуваний результат

Перед виїздом зрозуміло, який із трьох сценаріїв застосовується, який один інтерфейс береться, як audio physically залишає цей інтерфейс, і які речі ще треба підтвердити з майданчиком.

## Типові помилки та безпечне відновлення

| Помилка | Чому це проблема | Безпечна дія |
| --- | --- | --- |
| Взяти один `L` або `R` cable для stereo-файлу | Частина аранжування може зникнути | Підготувати перевірений mono mix або використати два канали |
| USB cable заряджає, але не передає дані | AMS-24 не з’явиться як interface | Взяти перевірений USB data cable |
| Підключити Bose на високому level | Можливий несподівано гучний звук | Зменшити level перед підключенням і піднімати поступово |
| Вважати, що будь-який FOH має два XLR-входи | Сценічна схема може відрізнятися | Завчасно надіслати FOH повідомлення вище й взяти перевірений mono fallback |
| Визначити кабелі TC-Helicon за пам’яттю | Роз’єми й спосіб виведення залежать від обраного routing | Спершу створити й перевірити окрему схему TC-Helicon за повним офіційним manual |
