## Терміни

| Термін | Просте пояснення саме для цієї системи |
| --- | --- |
| **Backing track** | Попередньо підготовлений аудіофайл, який MainStage відтворює під час виступу. У базовій фазі це один готовий stereo-файл на пісню без твоєї живої акустичної гітари та основного вокалу. |
| **Stereo** | Два пов’язані канали: лівий (`L`) і правий (`R`). Через два канали FOH вони можуть створювати просторову картину міксу. |
| **Mono** | Один канал. Для однієї Bose S1 Pro+ stereo backing track потрібно правильно сумістити в mono; не можна просто залишити один із двох каналів. |
| **Stem** | Окрема група музики — наприклад барабани або бек-вокал. Stems не є частиною базової системи; вони з’являться у Фазі 2. |
| **Audio interface** | Пристрій, який передає звук між MacBook і аналоговими роз’ємами. У цій системі це або CQ-12T, або Zoom AMS-24, але не обидва одночасно. |
| **Input** | Вхід у пристрій: наприклад сигнал від TC-Helicon до CQ-12T/AMS-24. |
| **Output** | Вихід із пристрою: наприклад stereo signal з CQ-12T до FOH. |
| **FOH** (`Front of House`) | Звукова система й/або звукорежисер, що відповідає за звук для глядачів. У великому сценарії FOH отримує від тебе готовий stereo mix. |
| **Gain** | Початкове підсилення вхідного сигналу. Невдалий gain може створити шум або clipping ще до регулювання гучності каналу. |
| **Level / Volume** | Рівень гучності каналу або виходу після того, як сигнал уже зайшов у систему. Перед підключенням і вимкненням він має бути зменшений. |
| **Clipping** | Перевантаження сигналу: він стає занадто гучним для конкретного етапу тракту й може спотворюватися. Це не творчий ефект, а помилка рівня, яку треба усунути. |
| **Phantom power / 48 V** | Живлення, яке деякі мікшери подають через XLR для condenser microphones. У поточній конфігурації воно не потрібне; для Zoom воно одночасно впливає на обидва XLR-входи. |
| **Concert** | Найвищий рівень проєкту MainStage: увесь твій концертний файл і спільні налаштування. |
| **Set** | Група patches усередині Concert. У цьому проєкті структура `Set` буде визначена після вибору способу секційного керування. |
| **Patch** | Зазвичай один робочий стан MainStage: для цього проєкту найчастіше пов’язаний із конкретною піснею або її частиною. |
| **Channel strip** | Смуга в MainStage mixer, яка приймає, відтворює або відправляє звук. |
| **Playback plug-in** | Інструмент MainStage для відтворення backing tracks. Він має waveform display, markers і групове керування кількома Playback instances; точну реалізацію повтору приспіву ми оберемо лише після домашнього тесту. [Apple: Playback interface in MainStage](https://support.apple.com/en-bh/guide/mainstage/mstg93cd8d05/mac) |
| **Marker** | Позначка позиції всередині аудіофайлу. У MainStage Playback вона потенційно дозволяє переходити до частин композиції, але її поведінка в нашій схемі має бути підтверджена окремим тестом. |
| **MIDI** | Мова керувальних повідомлень, а не сам звук. AIRSTEP Lite надсилає MIDI-команди MainStage через Bluetooth; MainStage пов’язує їх із діями. |
| **MIDI Learn** | Функція MainStage, яка «слухає» натискання на контролері й прив’язує його до екранної кнопки чи параметра. Для AIRSTEP Lite точні кроки створюватимуться лише після перевірки офіційної документації Xsonic та тесту з MainStage 4.3. [Apple: MainStage User Guide](https://support.apple.com/guide/mainstage/welcome/mac) |
| **Latency** | Затримка між дією/звуком і тим, коли ти його чуєш. У базовому сценарії головна ціль — стабільне відтворення backing track; налаштування latency з’явиться лише там, де воно реально впливає на результат. |

## Очікуваний результат

Після прочитання достатньо розуміти схему: **MainStage відтворює backing track → CQ-12T або Zoom AMS-24 зводить його з живим сигналом після TC-Helicon → Bose або FOH відтворює готовий результат**.

## Як перевірити

Ти маєш уміти відрізнити:

1. аудіо (`backing track`, гітара, вокал) від MIDI-команди AIRSTEP Lite;
2. stereo-вихід для FOH від mono-виведення на одну Bose S1 Pro+;
3. `gain` від звичайної гучності (`level`).
